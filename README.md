# 동작그만

카드샤크에서 영감을 받은 온라인 섯다 게임. Unity 6 + Unity Relay로 만들어서
포트 개방 없이 인터넷으로 바로 같이 할 수 있습니다.

## 설치

[Releases](../../releases)에서 `동작그만_설치.exe`를 받아 실행하세요.
필요한 파일은 알아서 내려받습니다.

윈도우가 "PC를 보호했습니다" 경고를 띄우면 **추가 정보 → 실행**을 누르면 됩니다.
서명 인증서가 없는 개인 제작 프로그램이라 뜨는 경고입니다.

## 하는 법

- 방을 만들고 초대 코드를 알려주면 상대가 그 코드로 들어옵니다
- 패를 돌릴 때 박자에 맞춰 누르면 밑장 빼기가 티 나지 않습니다
- 상대가 사기 치는 걸 잡아내면 그 판은 그대로 끝납니다
